# Library Management System

A simple menu-driven Library Management System developed using Python.

## Features
- Member registration
- View all registered members
- Search member using member ID
- View available books
- Issue books to members
- View issued book records
- Calculate library fines

## Python concepts used
- Functions
- Conditional statements
- Loops
- Lists and dictionaries
- Modules and imports
- File handling using JSON

## Requirements
- Python 3.8 or later
- No external packages required

## How to run
1. Download or clone this repository.
2. Open the project folder in VS Code or a terminal.
3. Run:

```bash
python main.py
```

The program automatically creates a `data` folder to store member and issued book records.

## Project note
This is an educational demonstration project. Do not use real personal information.
